Q2(c) · Find the second-largest offset and whether andi 1023 fits on the 1000-register processor. pp. 1–2
Worked answer
WIDTH
1000 register names need 10 bits each. The immediate field has 32−6−10−10 = 6 bits.
OFFSET
Under the slide’s unsigned-byte assumption the second-largest field value is 62. If the question instead asks for the second-largest aligned word offset, use 56 (largest 60). A usual signed 6-bit offset has maximum 31 and second-largest raw positive offset 30.

Q2(c) · With 64 registers, a 32-bit instruction and 6 opcode bits, find the maximum directly reachable array index in lw. pp. 1–2
Worked answer
WIDTH
32−6−6−6 = 14 offset bits. Under normal signed MIPS-style byte offsets, the largest positive offset is 8191, and the largest aligned offset is 8188. For four-byte elements the largest nonnegative index is 2047.
OTHER READING
If the question instead assumes an unsigned offset, the largest aligned offset is 16380 and last index is 4095. With a register holding the computed element address, a single offset field is no longer the array-size limit.

Q2(c) · Can sll $t0, $s1, 40 be encoded as written? pp. 1–2
Worked answer
WIDTH

Q2(c) · Find the maximum jump address of a hypothetical K-type with fields of 12, 10, 10 and 32 bits. pp. 1–2
Worked answer
FIELD
The 32-bit C/A field has maximum unsigned value 232 − 1 = 4,294,967,295.
AMBIGUITY
If the field is a byte address, that is the raw maximum and the highest aligned four-byte target is 0xFFFFFFFC. If it stores a four-byte instruction index in a wider address space, the assembled low address is 4 × (232 − 1) = 17,179,869,180 bytes. Q2(c) · Does having only 32 registers limit an array to 32 elements? Explain the largest reachable index. p. 2
Worked answer
STORAGE
Arrays live in memory. Registers hold a base address, an index or offset, and a value being used. Calculate base + 4i and use lw or sw.
LIMITS
One normal signed 16-bit offset from a fixed base can reach aligned offsets 0 through 32764, for a largest nonnegative index of 8191. Computing the full address in a register removes that immediate limit. A full theoretical 32-bit byte address space holds 230 four-byte words, so an array starting at zero would have last index 230−1. Real address maps make the usable size smaller.

Q2(c) · What is the largest value possible in a J-type jump? pp. 1–2
Worked answer
FIELD
The unsigned 26-bit field reaches 226 − 1 = 67,108,863.
ADDRESS
After appending two zero bits, the largest byte offset within the PC+4 region is 0x0FFFFFFC. For low-region examples this is the maximum target. The full address also includes the high four bits from PC+4, so there is no single global distance from the current instruction.
