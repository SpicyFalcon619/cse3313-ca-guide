Where does 5 + 3 happen?

Start with three named places inside the CPU and watch what each instruction changes.

CT-2 from scratch / Lesson 1 of 8 / Lectures 2–3

Follow the program into the CPU

The CPU is the part that runs instructions. An instruction is one small job, such as adding two numbers. When you open a program, the operating system brings its needed instructions and data from storage into main memory, often called RAM. The CPU fetches instructions from there and runs them.

Inside the CPU, a register is a small place that holds one value while the CPU works. We’ll use three named registers. A register’s name stays the same as its value changes. MIPS is the set of instructions and rules we’re using to tell the CPU what to do.

Run one instruction at a time

Read a line from left to right. The first word, such as addi, tells the CPU what job to do. A name starting with $ refers to a register. For the arithmetic below, the first register is where to put the answer. Then come the two inputs, separated by commas.

addi adds a number written in the instruction to a register value. $zero always holds 0. add adds the contents of two registers.

Before the program runs

Start with all three temporary registers at 0 for this example.

$t10$t20$t00
addi $t1, $zero, 5

Read 0, add 5, and put 5 in the first register, $t1.

$t15$t20$t00
addi $t2, $zero, 3

Read 0, add 3, and put 3 in $t2.

$t15$t23$t00
add $t0, $t1, $t2

Read 5 from $t1 and 3 from $t2. Put 8 in $t0. The two inputs keep their values.

$t15$t23$t08
What else is in the Lectures 2–3 slides?

Input brings data in, and output shows the result. Inside the CPU, control directs each operation, and the datapath moves and calculates values. A cache keeps copies close to the CPU for fast access. Cache typically uses SRAM, which holds a value while powered without periodic refresh. Larger main memory typically uses DRAM, which needs refresh. Both lose their contents when power goes off. SSD storage keeps files without power.

MIPS assembly is the readable text you just used. A compiler can translate C into assembly. An assembler turns an assembly instruction into the bits the CPU executes. You’ll do that by hand in Lecture 7.

Check my answer

How does a computer hold a number?

CT-2 from scratch / Lesson 2 of 8 / Lectures 2–3

Read 0101 as a number

A bit is a digit with two possibilities, 0 or 1. In decimal, place values go 1, 10, 100 from right to left. In binary, where there are two possible digits, the place values double instead.

80412011

Add the places with a 1. Here that’s 4 + 1 = 5. You can add zeros on the left to make eight bits, 00000101.

Group bits into bytes and words

Eight bits make one byte. In 32-bit MIPS, four bytes make one word. Each general-purpose register holds one word. The same 5 fills this whole register, with zeros in the unused positions.

Byte00000000Byte00000000Byte00000000Byte00000101

Move bits to change their place value

sll $t0, $t1, 2 shifts the bits in $t1 left two places, fills the freed right-hand places with zeros, and writes to $t0. With 5, 00000101 becomes 00010100, or 20. For the small array indices we’ll use, shifting left twice is the same as multiplying by four.

How do signed numbers and bitwise operations work?

To write −5 in eight bits, write 5 as 00000101, flip each bit to get 11111010, and add 1 to get 11111011. This is two’s complement. Extending −5 to more bits repeats its leftmost 1. This is how addi keeps a negative constant negative as it grows from 16 to 32 bits. addi $t0, $t1, -5 subtracts five from the value in $t1.

Bitwise operations compare bits in the same position. For 0101 and 0011, AND keeps only positions with two 1s (0001). OR keeps positions with at least one 1 (0111). NOR flips that OR result (1000 in this four-bit example). andi and ori take a constant. srl shifts right and fills the left with zeros.

Try it before you move on

Check my answer

One word is four bytes. In 0011 the 2 and 1 places are on, giving 3.

CT-2 from scratch / Lesson 3 of 8 / Lecture 5

Find the number’s address

An address is the number of a location in memory. Each address names one byte. An array is a list stored in order. In our example, A holds three four-byte integers, 5, 3 and 0. Its base address is where the first element starts. Assume $s0 holds that base, 100.

A[0]5Bytes 100–103A[1]3Bytes 104–107A[2]0Bytes 108–111

A[1] is one word after the first element. A word takes four bytes, so move four byte addresses from 100 to 104. The offset is how many bytes you move from the base.

Move a word between memory and a register

Read 4($s0) as “four bytes past the address held in $s0.” lw copies a word into a register. sw copies a word out of a register into memory.

lw  $t1, 0($s0)       # $t1 gets 5
      lw  $t2, 4($s0)       # $t2 gets 3
      add $t0, $t1, $t2     # $t0 gets 8
      sw  $t0, 8($s0)       # A[2] gets 8

Follow the data with your finger. Memory supplies 5 and 3, the registers hold them for the addition, and the store writes 8 at byte address 108.

Use a variable index

If the index i is in $t3, calculate the address first. Shift left twice to make 4*i. Add the base. Then load with zero extra offset.

sll $t4, $t3, 2       # byte offset
      add $t4, $s0, $t4     # address of A[i]
      lw  $t2, 0($t4)       # value of A[i]
Alignment, byte order and spilling

A MIPS word load or store starts at an address divisible by four. Byte order tells you which byte of the word goes at the lowest address. Big-endian puts the most significant byte first, little-endian the least significant first. If a program runs short of registers, it can use a store to keep a value temporarily in memory. That is spilling.

How does the CPU choose its next line?

Trace two possible paths using the sum you already know.

CT-2 from scratch / Lesson 4 of 8 / Lecture 5

Read one address at a time

The program counter, or PC, is the address of the instruction being run in our lecture examples. Each MIPS instruction is four bytes wide, so when nothing redirects the CPU, address 1000 is followed by 1004. A label is a name for an instruction address.

Skip a line if the values match

Assume $t0 holds 8 from the addition, $t1 holds the expected answer 8, and $t2 starts at 0.

1000  beq $t0, $t1, Done
      1004  addi $t2, $zero, 1
      1008  Done: add $s1, $t0, $zero

beq means branch if equal. 8 equals 8, so the next line is Done at 1008. If the values differ, the next line is 1004. bne branches when the values differ. j Done always jumps to the label.

Go back to repeat a job

A loop is a set of instructions that can run more than once. Put a label at the check, branch to the end when the check fails, then jump back after the body. Here we add one until the counter reaches two.

      addi $t0, $zero, 0
      Check: slti $t1, $t0, 2
            beq  $t1, $zero, Done
            addi $t0, $t0, 1
            j    Check
      Done:

slti asks whether the value is less than the constant. It writes 1 for yes or 0 for no. slt does the same with two registers. When the counter is 2, the answer is 0, so the branch exits.

How does a function return?

Give a function 5 and 3, then follow its result and its return address.

CT-2 from scratch / Lesson 5 of 8 / Lecture 6

Tell the caller and the function what to share

A function is a named piece of a program that performs a job. The caller is the part asking for that job. Our caller asks addNumbers to add 5 and 3. Those input values are arguments. In MIPS, the first argument goes in $a0, the second in $a1, and the result here comes back in $v0.

1000  addi $a0, $zero, 5
      1004  addi $a1, $zero, 3
      1008  jal  addNumbers
      1012  add  $s0, $v0, $zero
      1016  j    After
      1020  addNumbers: add $v0, $a0, $a1
      1024  jr   $ra
      1028  After:
  1. Set up the inputs. The two addi instructions put 5 and 3 in the argument registers.
  2. Call the function. At 1008, jal means jump and link. Save 1012 in $ra, the return address register, and jump to 1020.
  3. Do the work. At 1020, put the sum 8 into $v0.
  4. Return. At 1024, jr $ra jumps to the address stored in $ra. The caller resumes at 1012 and copies the result to $s0.

The jump at 1016 keeps the caller from running through the function body again. Track two separate things when you trace the code. $v0 holds the answer (8). $ra holds the address where work resumes (1012).

Try it before you move on

Check my answer

It saves 2004, the address of the next instruction. The function puts the result in $v0.

Where can a function save a value?

Watch a function borrow a register and give it back with the original value.

CT-2 from scratch / Lesson 6 of 8 / Lecture 6

Give the old value somewhere to wait

Suppose $s0 contains 50 and a function wants to use it while it works. The caller expects 50 back. The function can store 50 in the stack, an area of memory used for temporary data during calls.

$sp is the stack pointer. It holds the address of the current top of the stack. In our example, it starts at 1000. To reserve space for one four-byte word, subtract four. The word starts at byte 996 and occupies bytes 996–999.

addi $sp, $sp, -4     # reserve four bytes
      sw   $s0, 0($sp)      # save 50 in memory
      # The function may now use $s0.
      lw   $s0, 0($sp)      # restore 50 to $s0
      addi $sp, $sp, 4      # release those four bytes
Before$sp = 1000While saved$sp = 996Word at 996 = 50After restore$sp = 1000

Save the return address when another call needs it

Imagine the caller asks addNumbers for 5 + 3, and addNumbers calls a helper. The second jal writes its own resume address to $ra. If addNumbers needs its original return address, it saves it before the second call and reloads it before jr $ra.

The space one function reserves for its own information is a stack frame. A function that calls itself is recursive. Each active copy can keep its own frame. Start with “Save and restore $s0” in the stack visualiser. Try the recursive example after you can explain why the original 50 comes back.

What if a function saves two registers?

Reserve 8 bytes and store the registers at offsets 0 and 4. Restore each from the same offset before adding 8 back to $sp. Code that needs a temporary $t register after a call is responsible for protecting its value. A function that changes a saved $s register must restore it before returning.

Check my answer

The new $sp is 992. The words start at 992 and 996, at offsets 0 and 4. Restore the words before setting $sp back to 1000.

How do instructions become bits?

Turn your first addition into one 32-bit instruction.

CT-2 from scratch / Lesson 7 of 8 / Lecture 7

Give each part of the instruction its own space

Think back to add $t0, $t1, $t2. The CPU needs to know the operation, the two inputs and where the answer goes. The assembler puts that information in separate groups of bits called fields. It writes register numbers (8 for $t0, 9 for $t1, 10 for $t2). The current numbers inside those registers, such as 5 and 3, stay in the registers.

The format for this instruction is R type. For a regular add, the opcode is 0, the function code is 32 and the unused shift amount is 0. The rs and rt fields name the two inputs. rd names the destination.

op · 6 bits000000rs · 5 bits01001rt · 5 bits01010rd · 5 bits01000shamt · 5 bits00000funct · 6 bits100000

Write the fields left to right. Notice that $t0 appears first in the assembly text but its number goes in rd, the fourth field in the bits. To write the whole instruction in hexadecimal, split the final bit string into groups of four. Each group becomes one hex digit. Here the result is 0x012A4020.

Use the same idea for a constant or a jump

I type has four fields of 6, 5, 5 and 16 bits. For addi $t0, $t1, 5, write opcode 8, input number 9, destination number 8, and the constant 5. For lw $s1, 200($s2), the constant field holds 200 bytes. For a conditional branch, the constant field instead holds how many instruction words to move from PC + 4.

J type has a 6-bit opcode and a 26-bit jump field. For the slide’s j 2000 in the low address region, write opcode 2 and 2000 ÷ 4 = 500 for the jump field. Divide because instruction addresses are spaced four bytes apart. The CPU uses the upper four bits of PC + 4 to select the region.

Work through one branch offset

The lecture puts bne $s1, $s2, 1104 at byte address 1000. Start counting from 1004, the following instruction. The distance to 1104 is 100 bytes. Divide by four to encode 25 words. The decimal fields are 5 / 17 / 18 / 25. A backward branch has a negative offset.

How do four bits become one hex digit?

Four bits can hold any number from 0 to 15. Hex writes 0–9 as usual, then uses A, B, C, D, E and F for 10–15. For example, 1010 is 8 + 2 = 10, or A in hex. Grouping bits in fours always starts at the right-hand end.

What if the exam changes the number of registers?

Each bit doubles the number of names a field can hold. Four bits give 16 names, five give 32, and six give 64. If the question gives 16 registers and keeps a 32-bit I-type instruction with a 6-bit opcode, each register field takes four bits. That leaves 32 − 6 − 4 − 4 = 18 bits for the immediate. Check whether the question treats that field as signed or unsigned before finding its range.

CT-2 from scratch / Lesson 8 of 8 / CT-2 practice

Array A starts at byte 100 and holds [5, 3, 0]. $s0 holds 100. You want to pass the first two values to a function and write the answer into A[2]. Assume the course’s simplified call model.

1. What two instructions put the inputs in $a0 and $a1?
lw $a0, 0($s0)
      lw $a1, 4($s0)

The first word starts at the base. The second starts four bytes later.

2. If jal is at 1008, where does the function return?

It returns to 1012. jal saves 1012 to $ra. The function returns with jr $ra.

3. What result does the function return, and how do you store it?
add $v0, $a0, $a1   # in the function
      sw  $v0, 8($s0)     # in the caller, after return

The sum 8 returns in $v0. A[2] is eight bytes past the base.

4. What would change if the function called a helper?

If it needs to return through its original $ra, save that value before the new jal and restore it before returning. One saved word needs four bytes.

5. What are the four decimal fields for sw $v0, 8($s0)?

43 / 16 / 2 / 8. The opcode is 43 for sw. The base goes in rs ($s0 is number 16), the register containing the value goes in rt ($v0 is number 2), and 8 is the byte offset.
