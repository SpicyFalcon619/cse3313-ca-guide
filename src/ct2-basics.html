What runs the program?

A program is a set of instructions for a computer. An instruction tells the computer to do one small job. Data is what the job works on. In an addition program, “add” is the job and 5 and 3 are the data.

→
Main memoryProgram ready to run
→
CPURuns instructions

The operating system (for example, Windows) loads the needed parts of the program from storage into main memory, commonly called RAM (random access memory). Random access means memory can go straight to a named location. The CPU, or central processing unit, reads an instruction, works out what it means, and carries it out. These jobs are called fetch, decode, and execute.

The five components in your slides

Input brings in the numbers, for example from a keyboard. Memory holds the instructions and data in use. Inside the CPU, control directs the work and the datapath moves values and adds them. Output shows 8, for example on a screen.

Why do we have several places to keep data?

  • A register is a small named place inside the CPU for a value it is using now. Our next lesson puts 5 and 3 into registers.
  • A cache keeps nearby copies of instructions and data the CPU might need again. Cache typically uses static RAM (SRAM). A little circuit holds each bit while powered.
  • Main memory holds larger amounts of active program and data. It typically uses dynamic RAM (DRAM). It stores electrical charge and must refresh it as it leaks. It usually costs less per bit than SRAM. Cache and main memory are volatile, meaning they lose data without power.
  • Secondary storage, such as a solid-state drive (SSD), hard disk, or USB drive, keeps files without power. That makes it non-volatile. Read-only memory (ROM) is another way to keep data without power, often for built-in startup instructions called firmware.

Try it before you move on

Which part adds the numbers? Which place keeps the saved program after power is off?

Check my answer

The CPU’s datapath does the addition under the direction of control. Secondary storage, such as an SSD, keeps the saved program.

Where does 5 + 3 happen?

Start with three named places inside the CPU and watch what each instruction changes.

Course outline / Lesson 2 of 22 / Lectures 2–3 Instruction and term index

Give names to three places that hold numbers

The computer in Lesson 1 needs somewhere to hold 5 and 3 during the addition. We’ll use $t1 and $t2 for the inputs, and $t0 for the answer. The letter t is for temporary. Each of these registers is a small named slot inside the CPU.

Run one instruction at a time

Read a line from left to right. The first word, such as addi, tells the CPU what job to do. A name starting with $ refers to a register. For the arithmetic below, the first register is where to put the answer. Then come the two inputs, separated by commas.

addi means add immediate. It adds a number written in the instruction to a register value. An immediate is a number provided directly, like 5. $zero always holds 0. add adds the contents of two registers.

Before the program runs

Start with all three temporary registers at 0 for this example.

$t10$t20$t00
addi $t1, $zero, 5

Read 0, add 5, and put 5 in the first register, $t1.

$t15$t20$t00
addi $t2, $zero, 3

Read 0, add 3, and put 3 in $t2.

$t15$t23$t00
add $t0, $t1, $t2

Read 5 from $t1 and 3 from $t2. Put 8 in $t0. The two inputs keep their values.

$t15$t23$t08

Read the name of the job first. That short name, such as add, is called the mnemonic. Each piece after it is an operand. In the last line, $t0 is the destination and $t1 and $t2 are sources. A source supplies an input. The destination receives the answer.

Try it before you move on

If $t1 holds 6 and $t2 holds 4, where does add $t0, $t1, $t2 put the result?

Check my answer

It puts 10 in $t0. The first register is the destination. The two source registers still hold 6 and 4.

Reading C and translating arithmetic

Give every variable a register. Then translate one calculation at a time.

Course outline / Lesson 3 of 22 / Lectures 2–3 Instruction and term index

Read the little C program first

C is a programming language people write. In int total = 5 + 3;, int means the value is a whole number, total is the name we give that value, and = means put the result on the right into the variable on the left. A variable is a name for a value a program can use or change. The semicolon ends the statement.

A compiler can turn C into assembly, the readable names for the processor’s instructions. An assembler turns assembly into machine code, the bits the CPU understands. The instruction set architecture (ISA) is the agreement about the instructions, registers, and how the bits are interpreted. MIPS is the ISA in this course. The slides call MIPS a RISC architecture, which means its instruction design favours relatively simple, regular operations.

Map names to registers before writing code

Take f = (g + h) - (i + j);. Assume g, h, i, and j are already in $s1, $s2, $s3, and $s4. Write the mapping on your paper. Use $s0 for f and two temporary registers for the bracketed sums.

add $t0, $s1, $s2   # left sum = g + h
add $t1, $s3, $s4   # right sum = i + j
sub $s0, $t0, $t1   # f = left sum - right sum

sub means subtract. Do the second operand minus the third operand. An operand is any piece supplied to an instruction, including where to put the answer. # starts a comment in these assembly examples. A comment explains the line for people. The assembler reads the instruction before it.

addi means add immediate. The immediate is a number written right in the instruction. addi $s0, $s0, 1 reads the old value, adds 1, and writes back. Use addi $s0, $s0, -5 to subtract the constant 5. To copy a value, add zero. move $t0, $s0 is assembly shorthand (a pseudoinstruction) for a copy. On paper, add $t0, $s0, $zero is an explicit real instruction for the same copy.

Try it before you move on

If $s0 is 8, what does addi $s0, $s0, -5 do? What is the immediate?

Check my answer

The CPU adds −5 to 8 and leaves 3 in $s0. The number −5 is the immediate.

How does a computer hold a number?

Read the bits for 5 before working with addresses or machine code.

Course outline / Lesson 4 of 22 / Lectures 2–3 Instruction and term index

Read 0101 as a number

A bit is a digit with two possibilities, 0 or 1. In decimal, place values go 1, 10, 100 from right to left. In binary, where there are two possible digits, the place values double instead.

80412011

Add the places with a 1. Here that’s 4 + 1 = 5. You can add zeros on the left to make eight bits, 00000101.

Group bits into bytes and words

Eight bits make one byte. In 32-bit MIPS, four bytes make one word. Each general-purpose register holds one word. The same 5 fills this whole register, with zeros in the unused positions.

Byte00000000Byte00000000Byte00000000Byte00000101

Write a number as bits

To write 6 using the places 8, 4, 2 and 1, ask whether each place fits. Eight is bigger than 6, so start with 0. Four fits, so write 1 and leave 2. Two fits, so write another 1 and leave 0. One is too large for what remains, so end with 0. That gives 0110.

A register also has a number. For example, $t0 is another name for register 8. That slot can hold any word value. The register’s number tells the CPU which slot you mean, and the bits inside it tell you what value it currently holds.

Try it before you move on

How many bytes are in one MIPS word? What number is binary 0011?

Check my answer

One word is four bytes. In 0011 the 2 and 1 places are on, giving 3.
