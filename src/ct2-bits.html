Negative numbers and field widths

Use a fixed number of bits to write −5 and recognise a number that will not fit.

Lesson 5 of 22 / Lectures 2–3

See what eight 1s can mean

11111111 means 255 when we read it as unsigned, so every position adds its positive place value. If the same eight bits are read as signed two’s complement, the leftmost place is −128 and the other places add up to 127. The result is −1. The bits stay the same. The instruction or the question tells you how to read them.

Write a negative number

Start with +5 in eight positions. Flip every bit, then add 1 in binary. Any extra carry outside the eight positions is discarded. The last line is how −5 fits into eight bits.

StepEight bits
Write +500000101
Flip bits11111010
Add 111111011

To make a signed value wider while preserving it, copy its leftmost bit into the new positions. This is sign extension. So −5 becomes 11111111 11111011 in 16 bits. To extend an unsigned value, add zeros on the left. That is zero extension.

Count what can fit

Each bit doubles the possible patterns. Eight bits give 28 = 256 patterns. Unsigned uses 0 through 255. Signed uses −128 through 127. For n bits, unsigned is 0 through 2n − 1, signed is −2n−1 through 2n−1 − 1. addi uses a signed 16-bit immediate, from −32,768 to 32,767, and sign-extends it to the 32-bit register width. Overflow means an arithmetic result falls outside its available range.

What does sll mean?

sll stands for shift left logical. In sll $t0, $t1, 2, $t0 is where the result goes, $t1 supplies the bits, and 2 is how many places to shift. Each move fills the new rightmost place with 0 and discards whichever bit leaves the left edge. “Logical” means the new places are filled with zeros. The small display below shows eight of the register’s 32 positions.

For small numbers that fit, one left shift doubles the number. Two make it four times as large. srl stands for shift right logical. It fills from the left with 0 and drops bits on the right. For an unsigned value, one right shift divides by two and drops the remainder. So 5 becomes 2. For signed negative numbers, logical right shift does a different job from signed division.

    What does bitwise mean?

    Work with each pair of bits independently, with no carry from the next column. In the four low positions, use 5 (0101) and 3 (0011).

    InstructionWhen is the output bit 1?Low four bits
    andBoth input bits are 10001

    andi and ori do AND and OR with an immediate. andi $t0, $t1, 3 keeps only the two low bits because 3 ends in 11 and every other bit of the mask is zero. A mask is a bit pattern used to select positions.

    C writes bitwise AND as &, OR as |, and NOT as ~. NOT flips every bit. MIPS can flip a value by using nor with $zero. Read ~(a | 5) in two parts. First ori $t1, $t0, 5. Then nor $t1, $t1, $zero. The same pattern handles ~(a & n) by starting with and if n is in a register.
