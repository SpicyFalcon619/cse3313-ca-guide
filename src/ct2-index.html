Read the instruction

instruction, mnemonic, operand
An instruction is one job. Its mnemonic is the short name, such as add. Its operands tell it what to read, write, or use.
$ and register names
A name starting with $ denotes a register. $t0 is a named CPU slot (register 8). Its contents change while its name stays the same.
$zero, $0
Register 0 always reads as zero. Use it to initialise a register or copy a value by adding zero.
$t0–$t9 and $s0–$s7
The t names are temporary registers. A caller must save any t value it still needs after a call. A called function restores any s registers it changes.
$a0–$a3 and $v0–$v1
The a registers pass the first four arguments. The v registers can return results. A single integer result in our examples goes in $v0.
$sp, $ra, PC
$sp holds the current stack address. $ra holds the return address. PC is the program counter, the current instruction address in these examples.
C, int, =, ==, !=, ++, +=
C is a source language. int declares a whole-number value. = assigns, == compares for equality, != compares for difference, ++ adds one in place, and x += y means x = x + y.
label, colon, comma, parentheses, #
A label names an address and is defined with a colon. Commas divide operands. In 4($s0), the parentheses hold the base register. # starts a comment.
ISA, RISC, assembly, compiler, assembler
An ISA defines the processor’s instruction rules and registers. RISC describes a design approach using simple regular instructions. A compiler can turn C into assembly. An assembler turns assembly into machine code.

Calculate with values

add, sub
add $t0, $t1, $t2 writes $t1 + $t2 to $t0. sub with the same operands writes $t1 − $t2 to $t0.
addi, immediate, subi
addi $t0, $t1, 5 adds the constant 5 to $t1. The constant written in the instruction is an immediate. For subtraction of 5 use addi with −5.
move, li, pseudoinstruction
Some assemblers accept shorthand. move copies a register, and li loads a constant into a register. For a short signed constant you can use addi with $zero. Large constants can need more than one real instruction. Check what the exam asks you to encode.
bit, byte, word, binary, hex, 0x
A bit is 0 or 1. A byte has eight bits. A word here has 32 bits or four bytes. Binary is base 2 and hexadecimal is base 16. 0x marks a following number as hexadecimal.
signed, unsigned, two’s complement, sign extension
Signed values include negatives. Two’s complement gives the top bit a negative place value. Unsigned values use only nonnegative numbers. To widen a signed value, copy its top bit into the added positions.
sll, srl, sl
sll shifts bits left, srl shifts bits right, and both fill the empty positions with zeros. For example, 5 shifted left once gives 10, and shifted right once gives 2. In this course, write the full mnemonic. The letters sl alone could be a misreading of sll or slt.
and, or, nor, andi, ori, &, |, ~
AND keeps positions with two 1s. OR keeps positions with at least one 1. NOR flips the OR result. andi and ori take a constant. C writes AND as &, OR as |, and bitwise NOT as ~.
mul, div, mflo, mfhi, /, %
mul writes a product to its destination. div computes a quotient in LO and a remainder in HI. mflo and mfhi copy those results out. C uses / for division and % for remainder.

Move data or change direction

address, base, offset, index, alignment
An address identifies a byte location. Base is the starting address. Offset is the byte distance from it. An index counts elements. A standard MIPS word’s start aligns to a multiple of four.
lw, sw
lw loads a word from memory to a register. sw stores a word from a register to memory. Both use the address formed by adding a constant byte offset to a base register’s value.
big-endian, little-endian
The big-endian order places the highest-value byte first at the lowest address. Little-endian puts the lowest-value byte there. Both store the same four bytes.
spilling
Temporarily save a register value to memory to make room for other work.
slt, slti
Set if less than. slt compares two registers and writes 1 or 0. slti compares a register and a constant. Neither redirects execution.
beq, bne
beq branches if two registers are equal. bne branches if the two registers differ. If the test fails, the next line runs.
j, jal, jr
j jumps to a label. jal jumps and saves the next address in $ra in the lecture model. jr jumps to the address stored in a register. jr $ra returns.
&& and ||
In C, && requires both conditions to be true. || requires at least one condition to be true. Checking may stop as soon as the outcome is known.
caller, callee, argument, return value
The caller asks a function to run, and the callee is that function. Arguments are its inputs. A return value is the result it passes back.
stack, frame, leaf, recursion
The stack holds data temporarily during calls. A frame belongs to one active call. A leaf function makes no further call. Recursion means a function calls itself.

Write the bits of an instruction

field, opcode, funct, shamt
A field is a group of bits. The opcode identifies an operation or group. funct selects an operation within R format. shamt is the number of places to shift.
rs, rt, rd
These are register fields in an instruction. R-format arithmetic commonly reads rs and rt and writes rd. Their roles vary by instruction, so start from the example for that instruction.
R, I, J, encode, decode
MIPS has register, immediate and jump formats. Encoding turns assembly into numeric fields and bits. Decoding reads the bits back as assembly.
PC-relative, target, displacement, delay slot
A branch’s target is where it tries to go. The displacement is the distance from PC + 4, encoded in instruction words. A delay slot is the next instruction that some MIPS models execute even during a jump. The class examples use a simplified model without it.
