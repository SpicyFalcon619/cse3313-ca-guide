Computer architecture

Follow a program from storage to the CPU.

Content 01 of 09

Follow 5 and 3 through the computer

The SSD keeps the saved program. When you open it, the operating system puts the parts needed to run into RAM. The keyboard supplies 5 and 3. The CPU fetches the addition instruction. Inside the CPU, control works out what to do and the datapath adds the values. A later instruction sends 8 to the screen.

Why do we have different kinds of memory?

Main memory is typically DRAM, which must refresh the electrical charge that holds each bit. Cache typically uses faster SRAM for copies the CPU wants close by. Both lose data when power goes off. The SSD keeps saved files, and nonvolatile ROM can keep startup instructions. A compiler can translate C into assembly, and an assembler turns assembly into the bits the CPU reads.

MIPS assembly basics

Put 10 and 5 in registers, then calculate with them.

Content 02 of 09

Read the destination first

A register is a named slot inside the CPU. Here $t1 holds 10, $t2 holds 5, and $zero supplies 0. An immediate is a number written directly in the instruction.

addi $t1, $zero, 10  # $t1 = 0 + 10
addi $t2, $zero, 5   # $t2 = 0 + 5
add  $s0, $t1, $t2  # $s0 = 10 + 5 = 15
sub  $s1, $t1, $t2  # $s1 = 10 - 5 = 5

For the deck’s 12 + 8 − 5, add the registers holding the first two numbers, then use addi with −5. The intermediate result is 20 and the final result is 15. MIPS uses two’s complement for negative integers. In a four-bit example, start with 5 = 0101, flip every bit to get 1010, and add 1 to get 1011, which represents −5. MIPS applies the same rule to the 16-bit immediate and copies its sign bit to fill the 32-bit operand.

Work one bit at a time

10          1010
 5          0101
AND         0000
OR          1111
NOR         0000  # low 4 bits

AND requires two 1s in a column. OR requires at least one. NOR flips the entire OR result. The other 28 bits become 1, so NOR gives −16 in signed 32-bit MIPS. andi $s2, $t1, 3 keeps the last two bits of 10 and gives 2. ori $s3, $t1, 8 gives 10 because the 8s bit was already 1. A byte is eight bits, and a MIPS word is four bytes. Shifts move all the bits together and fill the empty spots with zeros. If $t0 holds 4 (0100), sll $t1, $t0, 1 writes 8 (1000) and srl $t2, $t0, 1 writes 2 (0010).

Processor performance, part 1

Calculate CPU time from the clock and the instruction mix.

Content 03 of 09

Decide what you are measuring

Response time is how long one job takes. Throughput is how many jobs finish per unit of time. Elapsed time includes waiting. CPU time counts CPU work for the task, including both user and system CPU time.

The deck gives A a 2 GHz clock and 10 seconds of CPU time. That is 20 billion cycles. B uses 1.2 × 20 billion = 24 billion cycles. To finish in 6 seconds it needs 24 billion ÷ 6 = 4 GHz.

Count cycles before averaging

The deck’s instruction classes A, B and C take 1, 2 and 3 cycles each. Sequence 1 uses 2 A, 1 B and 2 C, giving 10 cycles for 5 instructions. Its average CPI is 2. Sequence 2 uses 4 A, 1 B and 1 C, giving 9 cycles for 6 instructions. Its average CPI is 1.5. Divide cycles by clock rate for CPU time and by instruction count for average CPI.

Processor performance, part 2

Use the deck’s power and Amdahl problems to see what an improvement buys.

Content 04 of 09

Square the voltage ratio

In the deck, capacitance, voltage and frequency each become 85% of the old value. Dynamic power is proportional to capacitance × voltage² × frequency, so the new-to-old ratio is 0.85 × 0.85² × 0.85 ≈ 0.522. The new CPU uses about 52.2% as much dynamic power. Power and heat can constrain speed, and more cores help when the work can be split.

Set aside the time that stays the same

The deck’s 280 ns program spends 180 ns on loads and stores, 80 ns on floating-point work and 20 ns on branches. Doubling overall speed gives a 140 ns budget. The unchanged work uses 100 ns, leaving 40 ns for loads and stores. The required speedup is 180 ÷ 40 = 4.5×.

The previous subquestion says “reduced by 20.” The slide treats this as 20 times as fast. Floating-point time becomes 4 ns and total time becomes 204 ns, saving 76 ns. State the assumption because 20% would give a different answer. Millions of instructions per second, also abbreviated MIPS, can be misleading because two programs may run different numbers of instructions.

MIPS memory and branches

Load an array word, then trace what happens when a condition changes.

Content 05 of 09

Find the address before reading the value

Use the deck’s k = B[3] + 5;. Put B’s base in $s4 and k in $s1. If B starts at byte 200 and B[3] holds 7, the index 3 gives offset 12 bytes. The load starts at 200 + 12 = 212.

lw   $t0, 12($s4)    # read the 7 at 212
addi $s1, $t0, 5     # k = 7 + 5 = 12

For the deck’s A[10] = h + B[i], shift i left twice to get i × 4. Add it to B’s base in a register, then load using 0(register). The offset in lw must be a constant. With h = 230 and B[i] = 7, store 237 at byte offset 40 from A’s base.

Here $s0 holds A’s base, $s4 holds B’s base, $s2 holds i, and $s3 holds h. Follow $t0 from 12, to 212, to the value 7 when i = 3 and B starts at 200.

sll $t0, $s2, 2       # $t0 = i × 4
add $t0, $s4, $t0     # $t0 = address of B[i]
lw  $t0, 0($t0)       # $t0 = value of B[i]
add $t0, $s3, $t0     # $t0 = h + B[i]
sw  $t0, 40($s0)      # A[10] = $t0

Try both sides of the branch

The deck adds x and y when they match and sets x to y/2 otherwise. Put x in $s0, y in $s1, and sum in $s3. Use a nonnegative y for this logical shift.

      bne $s0, $s1, Else
      add $s3, $s0, $s1
      j   Done
Else: srl $s0, $s1, 1
Done:

With 8 and 8, the branch falls through and sum is 16. With 7 and 8, it branches and x becomes 4. beq jumps on equal values. slt writes 1 if the first source is smaller. A separate branch can test that 1. slti compares against a constant. For a C condition joined by &&, skip the true path if either test fails.

MIPS loops

Follow a while, for and do-while in the order the CPU runs them.

Content 06 of 09

Test before running the body

The deck uses while (array[5] == k) { i++; }. Load array[5] at offset 20 and exit with bne when it differs from k. If they are equal and the body changes only i, the comparison stays true. The follow-up examples can change k in the body.

For for (i = 0; i < 10; i++) { k++; }, initialize i once. Use slti for the check and beq to exit when it writes 0. On each pass update k, increment i, and jump back. Starting at k = 5, ten passes give k = 15.

      addi $t0, $zero, 0   # i = 0, once
Loop: slti $t1, $t0, 10    # $t1 = 1 while i < 10
      beq  $t1, $zero, End # leave when $t1 = 0
      addi $s0, $s0, 1     # k++
      addi $t0, $t0, 1     # i++
      j    Loop
End:

Test after running the body

For do { sum += i; i++; } while (i <= 10);, start i at 1 and sum at 0. Add 1 before the first check. Eventually add 10 to 45, increment i to 11, and exit because i < 11 is false. The sum is 55.

For the deck’s remainder shortcut, try 13 % 4. Shift right twice to get 3, then left twice to get 12. Subtract 12 from 13 to get 1. This logical-shift shortcut assumes a nonnegative dividend.

MIPS functions and stack

Follow the deck’s calls, returned values and saved registers.

Content 07 of 09

Follow add(5, 10)

The caller puts 5 in $a0 and 10 in $a1. jal add jumps to the function and saves the resume address in $ra. The function writes 5 + 10 = 15 in $v0. jr $ra returns and the caller adds another 15 to get 30. In the course’s simplified model, a call at byte 1008 saves 1012. The address 1012 and the result 15 are separate values.

Do the four-argument example with real numbers

With x = 15 and y = 7, the caller computes m = 32 and n = 2. It passes 15, 7, 32 and 2 in $a0 through $a3. The function returns 50 + (15 + 7) − (32 + 2) = 38. The caller then sets n = 38 − 7 = 31.

The function needs $s0 through $s3 for its own values. Save the caller’s four words first. Four words use 16 bytes. Starting with $sp = 1000, subtract 16, then the slots start at 984, 988, 992 and 996. Use sw to save and restore each with lw from the same slot before adding 16 back. A nested call writes a new $ra, so save the old one if you still need it.

MIPS machine language

Encode R, I and J instructions using the deck’s examples.

Content 08 of 09

Fill the R-format fields

For add $s1, $s2, $t1, use source numbers 18 and 9 and destination number 17. The opcode selects the group, and the function field selects addition.

op     rs    rt    rd    shamt funct
0      18    9     17    0     32
000000 10010 01001 10001 00000 100000

srl $s1, $s2, 20 uses 0 / 0 / 18 / 17 / 20 / 2. The input goes in rt. The shift count goes in shamt, whose five bits can hold 0 through 31. jr $ra uses register 31 in rs and function code 8.

Work out what the last field measures

  • andi $s1, $s2, 223 uses 12 / 18 / 17 / 223. Its immediate is unsigned.
  • lw $s1, 200($s2) uses 35 / 18 / 17 / 200. The final number already counts bytes. A store uses opcode 43. Use a numeric zero in sw $ra, 0($sp).
  • For bne $s1, $s2, Target, rs is 17 and rt is 18. Count instruction words from PC + 4. The deck’s 25 is correct if 100 means a displacement of 100 bytes from PC + 4. For example, a branch at 1000 targeting 1104 encodes (1104 − 1004) ÷ 4 = 25. If 100 means the target address, you need the PC to calculate the displacement.
  • For j 2000 in the low address region, encode opcode 2 and field 500. For jal 10000, use 3 and 2500. The field holds target bits 27 through 2. The CPU takes the top four bits from PC + 4 and appends two zeros.

Computer arithmetic

Multiply and divide in binary one step at a time.

Content 09 of 09

Multiply 6 × 7 by shifting and adding

Write the factors as 0110 and 0111. Read the multiplier from the right. Its first three bits are 1, so add 6, 12 and 24. Its last bit is 0, so skip it. The product is 42, or 00101010.

In the optimized version, start with 0000 0111. If the rightmost bit is 1, add 6 to the upper half, then shift the entire register right, including any carry. The four results are 0011 0011, 0100 1001, 0101 0100, and 0010 1010.

Divide 10 by 3 one quotient bit at a time

In 1010 ÷ 0011, bring down each dividend bit. If you can subtract 3, write quotient bit 1 and keep the difference. Otherwise write 0 and keep the partial remainder. A restoring divider tries the subtraction and adds 3 back when it goes negative.
